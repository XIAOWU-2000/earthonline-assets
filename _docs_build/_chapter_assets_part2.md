### 3.11.3 劫怪检索逻辑

**输入**：域代码 + 阻力序号（由起课结果推导）
**输出**：对应劫怪图片 + 劫名

```dart
// 伪代码，字段与 slots_165.json 一致
Future<JieGuai> loadJieGuai(String domainCode, int resistIndex) async {
  final sid = '${domainCode}-${resistIndex.toString().padLeft(2, '0')}';
  final list = await rootBundle
      .loadString('assets/data/slots_165.json')
      .then((s) => json.decode(s) as List<dynamic>);

  final hit = list.cast<Map<String, dynamic>>()
      .where((e) => e['id'] == sid)
      .toList();

  // 纪律 ①：找不到必须抛错，禁止静默返回默认值
  if (hit.isEmpty) {
    throw JieGuaiNotFoundException(sid);
  }
  if (hit.length > 1) {
    throw JieGuaiDuplicateException(sid);
  }

  final e = hit.single;
  if (e['done'] != true) {
    throw JieGuaiAssetMissingException(sid, e['file'] as String);
  }

  return JieGuai(
    id: e['id'] as String,
    name: e['name'] as String,
    assetPath: 'assets/monster/${e['file']}',
    resist: e['resist'] as String,
  );
}
```

> **禁止**：用 `switch` 硬编码 165 个分支；用默认图兜底；匹配不上时返回第一只怪。

### 3.12.1 自动质检脚本

### 3.12.2 质检项与阈值

| # | 检查项 | 通过标准 | 违反后果 |
|---|---|---|---|
| 1 | 尺寸 | **1024×1024** | 重画 |
| 2 | 白底纯度 | 四角 40×40 采样与纯白距离 **< 1** | 重画（灰底 / 有背景即失败） |
| 3 | 主体占比 `fill` | **0.05 ≤ fill ≤ 0.75** | 过小=主体丢失，过大=铺满无留白，均重画 |
| 4 | 两两相似度 | **MAE ≥ 12**（灰度 0.6 + 彩色 0.4 加权） | 低于 12 判定撞脸，重画其中一只 |
| 5 | 整体亮度 | 平均亮度 **120 ≤ L ≤ 245** | 过暗 / 过亮重画 |
| 6 | 文件完整性 | 可正常解码，无 <20KB 异常小文件 | 重新生成 |
| 7 | 槽位映射 | 165 个槽位**全部**有对应文件，无孤儿文件 | 补登记或清理 |

**当前全库实测值**：

