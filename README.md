## ⚠️ 合规边界（符箓部分，必读）

符箓采用道教符箓的**视觉形式**，但做了明确的内容隔离。这是本项目能否上线的关键之一。

| ✅ 取（视觉形式） | ❌ 不取（宗教内容） |
|---|---|
| 三段式结构：符头 / 符胆 / 符脚 | 真实咒语文字 |
| 云篆的**笔画形态**（盘绕、回旋、似字非字） | "敕令"等宗教术语 |
| 朱砂 + 黄纸 + 墨的**配色** | 神明名讳 |
| 方形朱印的**形式** | 真实道观印文、可"启用"的符 |

**核心规则**：

> **符胆写的字，是产品的符名（如上善若水），不是道教咒文。**
> **法印内容是卦象与编号，不是道观印文。**

所以它是**"真符箓的样子"**，不是**"真符箓"**。

C 级禁用词（吉/凶/宜/忌/报应/业障/神仙/符咒/天机/注定/转运/改运/开光/消灾/驱邪/法事/供奉）在任何可见文案中均不得出现。

### 01_符箓

| 文件 | 说明 |
|---|---|
| `talisman_zhusha.svg` | **朱砂黄纸**（传统样式）。黄纸底纹 + 朱砂渗染 + 手绘抖动滤镜 |
| `talisman_cyber.svg` | **赛博霓虹**（代码道场皮肤）。**与朱砂版共用同一套云篆路径**，仅换配色与表面处理 |

**两版共用结构**——这证明了皮肤系统可行：

```
符头 · 三勾（三道弧线 + 中轴）
  ↓
符胆 · 云篆「上善若水」四字（盘绕笔画，似字非字）
  ↓
法印 · 方形朱印（内嵌卦象 ☵ 坎）+ 编号 #023
  ↓
符脚 · 罡气盘绕 + 三重圈 + 收笔
```

**换画风的方法**：保留 `<path>` 结构，替换 `fill` / `stroke` 与滤镜，即得新皮肤。

规格：240 × 660（1:2.75）· 双线外框 · 顶部标签可删

**《尸兄》画风执行要点（v3 总结，AI 已验证）**：

| 项 | 规格 |
|---|---|
| 轮廓 | **粗黑纯黑**，厚度由形状决定（不要均匀） |
| 线条 | **手绘墨水感**（AI 用 "rough hand-drawn ink linework"） |
| 体积 | **cel-shading + 软光影 + 高光** |
| 一怪一记忆点 | **辨识度的来源**，每个怪物都该有一眼可记的特征 |
| 表情 | **有戏**（贼笑、呆滞、哀伤等具体情绪），不只"瞪眼" |
| 姿势 | **身体语言**（抱膝、双手合十等）配合表情 |
| 配色 | 单色调 + 1–2 处红色点缀（不超过 10% 面积） |
| **禁忌** | **禁止可爱风、日系萌系、纯平涂、参数拉满的脏** |

**SVG 与 PNG 选型**：

| | SVG（手绘） | PNG（AI 生图） |
|---|---|---|
| 体积 | 小 | 大（每张 700KB–1.1MB） |
| 缩放 | 任意 | 受像素限制 |
| **完成度** | **低**——我的能力边界 | **高**——AI 的强项 |
| 皮肤切换 | 改 fill/stroke 即可 | 需每张皮肤单独生图 |
| **建议** | 仅用于骨架 / 线框 / 简单图标 | **用于角色、场景、插画** |

| 项 | v1（错） | **v2（对）** |
|---|---|---|
| 抖动滤镜 | scale 3–4.5 | **scale 1.2–1.8**（线条活而不烂） |
| 体积 | 纯平涂 | **径向渐变 + 高光 + 地面阴影** |
| 造型 | 五官堆砌 | **先定剪影，再放五官** |
| 辨识度 | 无记忆点 | **每只怪只有一个记忆点** |
| 轮廓 | 8–10pt 纯黑 | 7pt 纯黑 `#0A0A0A` |
| 局部红 | `#D93025` 点缀 | 同左，**只做点缀** |

**部件库用法**（解决"量不够"）：

```
一只怪 = A头型 + B体型 + C眼 + D嘴 + E肢 + F记忆点
         ×4      ×4      ×6    ×5    ×4    ×6     = 11,520 种
```

产出规则：**① 先定剪影（A×B）② 再定性格（C 眼 D 嘴）③ 最后加一个记忆点（F）④ 每只怪只用一个 F**

### 03_交互框架

| 文件 | 说明 |
|---|---|
| `flow_interaction.svg` | 全流程 + 转场契约 + 硬约束 |
| **`wireframe_digitalrain.svg`** | **★ 黑客帝国数码流版**（推荐）：黑底 + 卦象代码雨 + 荧光线条 + 终端标注 |
| `wireframe_components.svg` | 浅色版（v1 保留，用于黑白打印稿） |

**数码流版视觉要素**：

```
底色     #05070A + 卦象代码雨（opacity 0.04–0.16）
网格     20pt 青线 opacity 0.07
扫描线   1pt 间隔 6pt，opacity 3.5%
荧光     feGaussianBlur 双层叠加（禁 BackdropFilter）
标注     等宽字体 · 终端风格（P08_TODAY / &gt; MOBILE）
窗口     macOS 三色圆点标题栏
```

两份线框内容一致（移动端三屏 + PC 三栏 + 组件九态 + 动效降级），仅风格不同。
**给设计与前端看数码流版，给打印归档看浅色版。**

**转场契约**：

| 跳转 | 动效 |
|---|---|
| P08 → P10 | 共享元素转场 200ms decelerate |
| P10 → P11 | 手牌扇形展开 stagger 60ms / 320ms |
| P11 → P12 | 故障 glitch 120ms + 面板上滑 |

**组件九态**：Default · Hover(PC) · Pressed · Focused(PC) · Disabled · Loading(骨架屏，不用转圈) · Empty · Error · Success

**三级降级**：high / medium / low —— 帧率 <50fps 自动降级，低端机必须能跑 low。
